# NoClip – site (100 % statique, aucun serveur ni installation)
Ouvre `index.html` (double-clic). Tout le contenu (3 langues : FR, EN, AR) est dans **content.js**. Le bouton de langue est en bas à droite de chaque page.
- modifier un texte : change le `content` de la catégorie (# gros titre, ## titre moyen, ### petit titre, - puce, > encart, **gras**, --- séparateur)
- ajouter une catégorie : copie un bloc { ... } de content.js, colle-le à la suite et change slug / title / quote / summary / content.
Elle apparaît toute seule sur l'accueil, dans le menu et avec sa propre page (index.html#/ton-slug).
Police : assets/fonts/Nega.otf (déclarée en haut de style.css). Design : style.css. Comportement : site.js.
Images : dépose-les dans assets/img/ (voir LISEZMOI.txt dans ce dossier).
